# 02 — 上電與測試（zh-TW）

> **安全第一**：本板輸出直接驅動 ILDA 投影機。第一次上電請用**限流電源**、**先不接雷射**、先用示波器或假負載確認。
> 投影機的 interlock 迴路與 shutter 必須先驗證，再考慮接上雷射。

## 0. 準備

| 項目 | 建議 |
|---|---|
| 電源 | 可調雙電源 ±15 V，限流先設 **100 mA**（之後可放到 200 mA） |
| USB | 有資料傳輸的線；建議串一個 USB 電流表 |
| 電表 | 一般 DMM 即可 |
| 示波器 | 看 MCLK/BCLK/LRCLK/TDM 與類比輸出 |
| 假負載 | J1 每對差分接 1 kΩ（或 10 kΩ）到地，取代投影機 |
| 軟體 | Max/MSP 或任何可送 8 聲道 USB Audio 的程式 |

## 1. 階段 0：不上電檢查

1. 目視 J2 極性、D1/D2 方向、U1 pin 1、U31–U34/U21–U24 pin 1。
2. 用電表電阻檔量：
   - `+15A` 對 `GND`：不能是 0 Ω（電容會充電，讀值會上升）。
   - `-15A` 對 `GND`：同上。
   - `+5VA`、`+3V3` 對 `GND`：不能是 0 Ω。
3. 確認沒有錫橋在 U1 的 0.5 mm 腳距、U21–U24 的 0.65 mm 腳距。

## 2. 階段 1：只上 ±15 V（不插 USB）

限流 100 mA，慢慢升到 ±15.0 V。

| 量測點 | 預期 | 判定 |
|---|---|---|
| TP4 `+15A` | +15.0 ± 0.3 V | |
| TP5 `−15A` | −15.0 ± 0.3 V | |
| 輸入電流 | 約 30–50 mA（OPA 靜態） | 若 >100 mA 立刻斷電 |
| 發熱 | 無明顯燙手 | |

> 此時沒有 USB，`+5VA`/`+3V3` 都是 0，這是正常的。

## 3. 階段 2：只插 USB（不接 ±15 V）

| 量測點 | 預期 | 判定 |
|---|---|---|
| TP3 `+5VA` | 5.0 ± 0.15 V | |
| TP2 `+3V3` | 3.3 ± 0.1 V | |
| A1.26 `MCU_3V3` | 3.3 ± 0.1 V | |
| A1.7 `RAILS_GOOD` | **0 V**（±15V 未上） | |
| A1.4 `CODEC_RESET_GPIO` | 0 V（R373 下拉） | |
| J1 pin 13 `SHUTTER` | **0 V** | |
| USB 電流 | 約 100–200 mA | 若 >500 mA 斷電 |

- Teensy 應該能被電腦認到；若已燒錄 RevB 韌體，序列埠會印出 `ILDA8CH RevB-P4: ...`。

## 4. 階段 3：兩者都上，尚未 ARM

先插 USB，再上 ±15 V。

| 量測點 | 預期 | 備註 |
|---|---|---|
| TP4/TP5 | ±15.0 V | |
| TP3 `+5VA` | 5.0 V | |
| TP2 `+3V3` | 3.3 V | |
| A1.7 `RAILS_GOOD` | **3.3 V** | 兩軌都 >12 V 後 |
| A1.16 `ADC_P15` | **≈0.550 V** | 對應 +15 V |
| A1.17 `ADC_N15` | **≈0.558 V** | 對應 −15 V |
| TP11 `VQ` | ≈2.5 V | CS42448 中間電位 |
| TP6 `RUN_ENABLE` | **0 V** | 還沒 ARM |
| J1 pin 13 `SHUTTER` | **0 V** | |

序列埠每秒應印出類似：

```
codec=1 clock=1 stream=0 rails=15.00/-15.00 armed=0 blocks=0
```

- `codec=1`：I2C 初始化成功。
- `clock=1`：CS42448 的 MUTEC 狀態正常。
- `stream=0`：還沒送 USB 音訊。
- `armed=0`：還沒下 `a`。

> 若 `codec=0`，先量 `+5VA`、`+3V3`、`CODEC_RESET`（應為 3.3 V）、SCL/SDA 是否有 100 kHz。

## 5. 階段 4：USB 音訊與 ARM

1. 在電腦上把輸出設為 8 聲道、44.1 或 48 kHz。
2. 播靜音或極小訊號（Max：`dac~ 1 2 3 4 5 6 7 8`）。
3. 序列埠應變成 `stream=1`。
4. 送字元 `a`：
   - `armed=1`
   - TP6 `RUN_ENABLE` → **3.3 V**
   - J1 pin 13 `SHUTTER` → **≈5 V**
5. 送字元 `s`：
   - `armed=0`
   - `RUN_ENABLE` → 0 V
   - `SHUTTER` → 0 V

### Watchdog 驗證

1. ARM 後，把 USB 音訊停掉（或拔 USB 線）。
2. 應在 **<20 ms** 內 `stream=0`、`armed=0`。
3. 若只停 heartbeat（正常情況不會），`RUN_ENABLE` 會在約 **7 ms** 後掉。

### Rail 掉電驗證

1. ARM 後，把 +15 V 關掉。
2. `RAILS_GOOD` 應立刻掉、`RUN_ENABLE` 掉、shutter 掉、`CODEC_RESET` 掉。
3. 重新上電後**不會自動恢復**，必須重新送 `a`。

## 6. 階段 5：DC 輸出（不接投影機）

用 Max 送固定 DC（例如 `sig~ 1.0` → `dac~ 1`），量 J1：

| 訊號 | J1 pin | 預期 |
|---|---|---|
| X = +1.0（full scale） | 1（X+） | **+4.4 V** |
| | 14（X−） | **−4.4 V** |
| X = 0 | 1 / 14 | 0 V / 0 V |
| X = −1.0 | 1 / 14 | −4.4 V / +4.4 V |
| R = +1.0（gain 0.70） | 5（R+） | **+4.4 V**（超幅） |
| | 18（R−） | **−4.4 V**（超幅） |
| R = +1.0（gain 0.35） | 5 / 18 | +2.2 V / −2.2 V |

- X/Y 差動滿幅 ≈ ±8.87 V（ILDA ±10 V 的 89%）。
- 顏色在預設 gain 0.70 時差動 +8.87 V，是 ILDA +5 V 的 **1.77 倍**；校正後應為 +5 V（gain 0.394）或 +4.44 V（gain 0.35）。
- 若每腳只有一半，檢查是不是只量到單端；差分要量 P−N。

## 7. 階段 6：接投影機

1. 先用 ILDA 測試器或示波器確認 pin map 與極性。
2. 確認投影機 interlock 迴路（J1 pin 4/17 在板上短接）。
3. 把韌體 gain 暫時降到 0.3–0.5，送小圖形。
4. 確認 X/Y 方向、顏色順序、shutter 行為。
5. 再逐步回到 0.70 並做 [03-校正](03-校正-zhTW.md)。

## 8. 故障排除

| 現象 | 先檢查 | 可能原因 |
|---|---|---|
| `+15A`/`−15A` 為 0 | J2、D1/D2、外部電源 | 極性接反、二極體裝反、限流太低 |
| `RAILS_GOOD` 一直 0 | TP4/TP5、R23/R25、U6 | 分壓開路、比較器未供電、U36 |
| `+5VA` 為 0 | FB1、USB_5V | Teensy VIN 沒 5 V、FB1 開路 |
| `+3V3` 為 0 | U2、USB_5V | U2 壞、負載短路 |
| `codec=0` | `CODEC_RESET`、SCL/SDA、`+5VA` | reset 沒放、I2C 位址錯、codec 沒電 |
| `clock=0` | TP7/TP8/TP9、TDM_TX | MCLK/BCLK/LRCLK 沒出、TDM 格式錯 |
| `stream=0` | USB 音訊、取樣率、8ch | 主機沒送、只送 2ch、取樣率不符 |
| `armed=0` 按 `a` 沒用 | `rails`、`clock`、`stream` | 三者任一不正常 |
| `RUN_ENABLE` 週期性掉 | A1.6 heartbeat、U4 | 韌體卡住、monostable 時間不足 |
| Shutter 一直 0 | `CODEC_RESET`、U37、U5 | reset 低、buffer 沒致能 |
| 輸出一直是 0 | `RUN_ENABLE`、U21–U24、U31–U34 | TMUX/ADG 沒開、codec mute |
| 單一通道死 | 該聲道 OPA、ADG、TMUX、100 Ω | 焊接、零件方向 |
| 輸出有固定偏移 | 校正 | 見 [03-校正](03-校正-zhTW.md) |
